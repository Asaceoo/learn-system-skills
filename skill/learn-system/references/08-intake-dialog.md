# 08 · 开课三问弹窗（流程 A 第 1 步）

弹窗是**收集器**，不是流程闸门。它的全部价值是「用三次点击拿到本来要打三行字的信息」，
所以它必须便宜、可跳过、答案必须落盘。反过来：为了弹窗而卡住流程，是 bug。

## 1. 什么时候弹

- 触发条件只有一个：**`MISSION.md` 缺失**（流程 A 第 1 步）。
- 已有 `MISSION.md` → 不弹，直接读。
- 一个会话只弹一次。用户答完后本会话不再弹。

## 2. 怎么弹

1. 先 `widget_guidelines`（模块取 `interactive` 或 `mockup`）拿配色与尺寸规范。
2. 用 `show_widget` 渲染 `templates/intake-dialog.template.html`，**原样输出片段**，
   不要包 `<html>` / `<body>` / DOCTYPE。
3. 把模板里所有 `{{TOPIC}}` 替换成实际领域名（如「注塑」）。
4. 弹完**正常继续**：弹窗是并行的收集动作，不阻塞你去做深度调研。

## 3. 三问与代号

| 问 | 字段名 | 选项代号 | 落到 MISSION.md 哪 |
|---|---|---|---|
| Q1 为什么学 | `why` | A1 工作马上用 / A2 转岗求职 / A3 兴趣通识 | 动机 |
| Q2 什么算学成 | `goal` | B1 做出东西 / B2 通过考试 / B3 讲明白 | 成功判据 |
| Q3 怎么学 | `mode` | C1 标准 / C2 备考 | 模式 |
| Q3 每周几小时 | `hours` | D1 1-3 / D2 4-6 / D3 7+ | 节奏（用来算预期完成时间） |

### Q3 小时数 → 预期完成时间（换算表，别自己拍）

`horizon_weeks` 不能凭感觉给，按下表取默认值：

| 代号 | 每周小时 | 取中位 | horizon_weeks |
|---|---|---|---|
| D1 | 1-3 | 2 | 12 周 |
| D2 | 4-6 | 5 | 5 周 |
| D3 | 7+ | 9 | 3 周 |

推导：目标 8 个模块 × 每模块 2.5 小时 ≈ 20 小时，留 25% 给复习返工 → 25 小时总预算，
`horizon_weeks = 25 ÷ 每周小时中位`，向上取整。**大纲出来后按实际模块数与 `budget_hours` 重算并覆盖**。
到期日一律用 `date` 实取，不许心算（铁律 15）。

**Q3 是双选**：模式和小时是两个维度，必须都收到。只收到一个时，另一个按默认值
（`C1 标准` / `D2 每周 4-6 小时`）落盘，并在回复里明说「小时数没填，先按每周 4-6 小时算」。

## 4. 答案必须回写 MISSION.md

用户确认后**立刻**写 `MISSION.md`（结构用 `templates/mission.template.md`）：

- Q1 → 动机；Q2 → 成功判据；Q3 → 模式 + 每周小时（并据此算出预期完成时间）
- 写完后回复一句「已写入 `MISSION.md`，下次不再问这三件事」
- **不写 MISSION.md 就等于白问**：答案只活在对话里，下个会话又要问一遍

## 5. 用户不配合时的处置（不许卡住）

| 情况 | 怎么办 |
|---|---|
| 只选了一部分 | 用已选项开课，缺项在 `MISSION.md` 里写「未定」，大纲确认时补问一次。**不得等待** |
| 一直不点确认 | 等一轮；用户若转而说「直接开始」之类，按默认值 A3 / B3 / C1 / D2 落盘，**明确告知用了默认值、随时可改** |
| 回复的是散装文字而不是代号 | 从文字里提取三件事，**先把提取结果复述一遍**再落盘 |
| 明确说「别问了」 | 直接按默认值落盘 + 告知，不再追问 |

默认值不是猜测用户意图，是**让流程继续**；落盘时必须标注来源为「默认」而非「用户选定」。

## 6. 降级

无 `show_widget` / 无交互能力 → 退化为纯文本三问，每问带编号：

```text
学「X」之前定三件事，回复编号即可（如 A1 B2 C1 D2）：
Q1 为什么学？ A1 工作马上用 / A2 转岗求职 / A3 兴趣通识
Q2 什么算学成？ B1 做出东西 / B2 通过考试 / B3 讲明白
Q3 怎么学 + 每周几小时？ C1 标准 / C2 备考　·　D1 每周1-3 / D2 每周4-6 / D3 每周7+
```

不跳过，告知已退化。

## 7. 交卷清单（流程 A 第 1 步结束前逐项打勾，每条贴证据）

- [ ] 弹窗已出（`show_widget` 调用记录）或已按 §6 降级
- [ ] 三问齐全，没有出现第四问
- [ ] Q3 两个维度（模式 + 小时）都收到了，或用默认值并已告知
- [ ] `MISSION.md` 已写入（`cat` 实际内容），三件事都在
- [ ] 已告知用户「下次不再问」

## 8. 反模式

- **AI 替用户选**：弹窗还没回就自己填了 A1 —— 弹窗就成了装饰
- **问第四问**：模式已经并入 Q3，再单独问就是第四问
- **卡在等点击**：用户没点就什么都不做，流程 A 停摆
- **只答不写**：对话里聊完了，`MISSION.md` 还是空的
