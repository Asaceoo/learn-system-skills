# 出题与测验：零提示、有难度梯度、打薄弱点

出题的唯一目的是**暴露不知道的东西**，不是让学生觉得舒服。答对率高但题简单，等于没测。

## 一、零提示硬规则

违反任一条，题就废了：

1. **选项描述不得泄露正确性。** 错的写法：`label: "stderr"，description: "错误输出流，用于错误分类"`。对的写法：`label: "stderr"，description: "标准错误流"`，字数尽量对齐。
2. **不许出现「推荐」「最常见」「通常」这类暗示词**，也不许给正确项加「(推荐)」。
3. **正确项位置跨题打散。** 不许连续三题都是 B，也不许总是第一个。
4. **错误项必须是真概念构成的常见误解**，不是明显荒谬的凑数项。
5. **题干不得暗示答案。** 错的：「error() 用哪个错误流？」对的：「error() 的输出会去哪？」
6. **各选项字数接近**，避免用长度判断。

## 二、五种题型

| 类型 | 考什么 | 例 |
|---|---|---|
| 事实回忆 | 有没有记住 | 哪个状态码表示语义错误？ |
| 概念理解 | 知不知道为什么 | 为什么这里要用双检锁而不是普通加锁？ |
| 行为预测 | 会不会推演 | X 失败时，这段逻辑会走哪条分支？ |
| 辨析 | 会不会区分 | A 与 B 的根本差别在哪？ |
| 排障 | 有没有真用过 | 出现这个报错，最可能的原因是什么？ |

一份测验里至少覆盖 3 种。「事实回忆」占比不超过 40%。

## 三、难度配比

| 场景 | 易 : 中 : 难 |
|---|---|
| 首诊（摸基线） | 4 : 4 : 2 |
| 薄弱点复练 | 3 : 7 : 0（专攻中难点） |
| 日常复习 | 均分 |
| 考前冲刺 | 2 : 4 : 4 |

「难」指的是需要多步推理或跨概念组合，不是指背生僻细节。

## 四、薄弱点复练

针对 `mastery.md` 里 L1-L2 的概念：

1. **禁止原题重问。** 必须换语境、换角度、换提问方式，考同一个底层知识。
2. 例：上次错在「400 与 422 的区别」，这次给你一个全新场景，让你判断该返回哪个码。
3. 一次最多攻 2 个薄弱概念，多了分不清是哪个在起效。
4. 同一个概念连续两轮仍错 → 不是练得不够，是前置有洞，回退查前置。

## 五、累积测验

标准 / 备考模式下，每完成 2-3 个模块出一次累积测验：

- 8-10 题，混合各模块概念
- 每题标注 `source_modules`，便于回溯
- 至少 2 题是**跨模块组合**（考迁移，考不出迁移说明是碎片化记忆）
- 至少 1 题是**旧的已掌握概念**（防遗忘，答错说明复习档该降）

## 六、判分与反馈

1. 先给结果表：题目 / 正确答案 / 你的答案 / 结果。
2. 错的题给解释，但**只解释错因**，不重讲整块知识。重讲是教学，不是测验。
3. 每道题映射回概念名，名字必须和 `mastery.md` 里的完全一致，否则状态会分裂。
4. 全对时不要只说「很好」——加一道更难的变式，确认不是蒙的。

## 七、自检题（课内）

每节课末尾 3-5 题，目的不是评分而是**当场发现没懂**：

- 3 题基础 + 1 题变式 + 1 题纠错
- 允许用户先自答再看解析（折叠）
- 答错不扣分，但计一次错；**同一概念累计 2 次错**才创建 `mistakes.md` 并记入（不足 2 次先记在 `mastery.md` 备注）

## 八、题目质量检查

出完题逐条过：

- [ ] 遮住选项，光看题干能独立作答吗（说明题干信息够）
- [ ] 不懂的人能靠排除法/字数/语气猜对吗（能 → 重写）
- [ ] 正确项位置是否连续重复
- [ ] 错误项是否都是真概念
- [ ] 每题是否映射到一个具体概念名
- [ ] 是否至少覆盖 3 种题型
