# 来源与调研：教材锚定 + 深度调研协议

模型的记忆会过时、会把相似的东西缝合、会编出不存在的书名和链接。所有事实性内容必须有外部锚点。

## 一、来源优先级（从高到低）

| 级 | 类型 | 例 | 能支撑什么 |
|---|---|---|---|
| 0 | **用户提供的一手材料** | 厂标、检测报告、工艺文件、内部培训材料、现场照片 | 一切。行业隐性知识不在互联网上，这是唯一权威 |
| 1 | **现行强制/推荐标准** | GB / ISO / 行业标准 / 药典 / 建筑规范 | 是什么、必须怎么做 |
| 2 | **官方文档 / 原始规范** | 语言规范、RFC、官方 API 文档、论文原文、法条 | 是什么、为什么 |
| 3 | **教材 / 课程标准** | 国民教育序列教材、课程大纲、考试大纲 | 知识骨架、覆盖面基准 |
| 4 | 权威课程、经典著作、学会资料 | 公认教科书、官方培训材料 | 是什么（次一级） |
| 5 | 最佳实践、成熟教程、社区共识 | 被广泛引用的工程博客 | 只能支撑「怎么做」 |

第 4-5 级不得用于支撑定义与原理。手册类知识（工艺参数、公差、检测方法）以第 1 级为准；同理，教材与现行标准冲突时，**标准优先**。

## 二、知识基准：用教材骨架，不要自己发明顺序

稳定学科与快变领域，基准不同。先判断再选源：

| 类型 | 判据 | 基准 |
|---|---|---|
| 稳定学科 | 核心结论在过去 5 年没发生范式变化（数学、物理、化学、材料、机械、工艺、法律、医学基础、会计） | **教材目录 + 课程标准** |
| 快变领域 | 5 年内主流做法换过（AI、前端框架、云服务、工具链） | **官方文档 + 原始规范**；教材只作概念框架 |
| 强监管领域 | 有强制标准与准入要求（门业、建材、食品、医疗器械） | **现行标准 + 一手检测材料**，教材仅作原理参考 |

**教材骨架的用法**：找 2 个独立版本（不同作者/出版社/年代）的目录 + 1 份课程标准或考试大纲，取**并集**作为初始模块清单。教材目录不是学习顺序（那是作者的组织方式），但它是**覆盖面基准**——它列了而你没讲的，必须解释或补上。

## 三、深度调研协议（开课前必须跑）

四步，产出直接写进 `syllabus.yaml`：

1. **搭骨架**：按第二节选定基准，拿到 2 个独立目录 + 1 份课程标准。取并集成模块候选。
2. **做交叉**：对每个准备写进课的结论，找 **≥2 个独立来源**。
   - 两源一致 → 标「已交叉」
   - 两源不一致 → 标「存在分歧」，**两说都写出来**，附各自来源与年代，不要选一个当定论
   - 只有一源 → 标「单源」，不得升为「标准结论」
3. **查时效**：记下每份来源的版次与年份；快变领域额外核对最近 12 个月的官方变更说明。
4. **落地**：结果写进 `syllabus.yaml` 的 `anchor`（基准）与 `resources`（来源清单）；没解决的进 `unverified`。

调研不合格的标志：`resources.primary` 少于 3 条可开链接，或 `anchor` 写不出「用哪本教材/哪份标准做基准」。

## 四、断言三级，写课必须标

课内每句事实性陈述归入一类：

| 级 | 含义 | 要求 |
|---|---|---|
| 事实 | 来自可验证来源的定义、原理、规范、参数、史实 | 必须带小节级来源锚点 |
| 建议 | 教学取舍、工程经验、学习策略 | 标明是建议，不得伪装成事实 |
| 推断 | 由上述推理得出，无直接来源 | 必须写出「可推翻条件」：「如果 ___ 不成立，则本结论不成立」 |

写法示例：

```
事实：GB/T 规定的甲醛释放量限量见 [来源：GB 18580-2017，第 5 章]。
建议：初学先按「看限量等级就够」记，够用；深入再补检测方法差异。
推断：若该批板材的实际含水率高于 12%，本条工艺参数需下调——此为推断，未见标准明文。
```

## 五、覆盖度验收（防「假全面」）

「全面」不可能穷尽，改成可验收的定义：**声明范围内全覆盖 + 边界外明确声明**。

三查：

1. **概念查**：`syllabus.yaml` 里每个模块的 `concepts` 必须全部出现在某一课的正文或速查件中。缺一个 → 报「未覆盖」，不许含糊。
2. **差集查**：教材目录（或课程标准）与你的 syllabus 做差集。教材列了而你没讲的，要么补模块，要么写进该模块的 `not_covered` 并说明理由。
3. **边界查**：每个模块必须写一句「本模块不覆盖什么」。

声明内漏了算缺陷，声明外没讲不算。

## 六、拿不到来源时

按顺序退：

1. 换关键词（英文原名、标准编号、作者名）
2. 找二级来源（教材、权威课程）替代一级
3. 仍找不到 → 课内标注「以下为推断，未找到权威来源，建议核验方向：______」
4. **绝不**用「据研究」「业内普遍认为」这类无主体说法填空

## 七、`syllabus.yaml` 的来源区

```yaml
anchor:
  type: textbook          # textbook | official | standard
  basis: "《XX》第 3 版 目录 + 《YY》第 5 版 目录 + 课程标准 2024"
  cross_checked: 12       # 已交叉结论数
  single_source: 3        # 单源结论数（必须列出）
  disputed: 1             # 存在分歧的结论（两说都写）
resources:
  primary: []             # 级 0-2
  textbook: []            # 级 3
  secondary: []           # 级 4
  tertiary: []            # 级 5
  unverified: []
```

## 八、反模式

- 编书名（最常见）：宁可写「某经典教材第 X 章讲了这个」，也别编完整书目
- 编链接：结构看起来对，实际 404
- 用「研究表明」当论据
- 把 2020 年的答案当 2026 年的现状
- 只引二手解读，不引原文
- 引用与论点不对应（引了但没支撑那句话）
- 教材与现行标准冲突时盲信教材
- 把单源结论写成定论
