# 复习调度：复习档制间隔重复

不实现完整 FSRS 算法（那需要精确的数学计算，容易算错）。用离散的「复习档」，规则可手算、可核对、不会漂。

> **两个刻度不要混**：`mastery.md` 用 L1-L5 表示**掌握程度**；`review.md` 用 0-5 表示**复习间隔档**。两者不通约、不互相换算。同一个概念在两处都要有行，缺一边视为状态不完整。

## 一、复习档与间隔

| 复习档 | 0 | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|---|
| 间隔（天） | 1 | 3 | 7 | 16 | 35 | 75 |

新概念一律入 0 档，到期日 = 学完当天 + 1 天。

## 二、评级与复习档变更

每次复习只给三档评级，不给分数。**`复习档` 列记录的是本次复习之后的档**，`到期日` 由它算出——这两列必须自洽，否则调度会漂。

| 评级 | 判据 | 复习档变化（复习后） | 下次到期 |
|---|---|---|---|
| 忘记 | 答不出，或答错核心 | `max(0, 当前档 - 2)` | 今天 + 1 天（不走复习档间隔） |
| 勉强 | 答对但慢、犹豫、需要提示 | 不变 | 今天 + 当前档间隔 |
| 熟练 | 快速准确，且能说清为什么 | `min(5, 当前档 + 1)` | 今天 + 新档间隔 |
| 新入队 | 概念首次学完 | 0 | 今天 + 1 天 |

自检一行：复习后复习档是 2、评级「熟练」，到期日 = 今天 + 7 天。若写成「今天 + 16 天」，说明你把复习前的档填进了 `复习档` 列。

## 三、到期队列

每次复习开始时：

0. **进入 skill 的第一句先报「今天到期 N 条」**，不等人问。
1. 读 `review.md`，筛 `到期日 <= 今天`。
2. 排序：`逾期天数` 降序 → `复习档` 升序 → `上次评级为忘记` 优先。
3. 截取前 12 条。剩余下次继续，不硬塞。
4. 队列为空时不强行复习：改为推进新模块，或做一次累积测验。

## 四、复习不是重讲

一次复习的三个动作，顺序固定：

1. **抽问**（2 分钟/概念）：直接问题，不给铺垫。
2. **对答案 + 只说错在哪**：不重讲整块知识。用户要求重讲时，那是新课，记一笔「需重学」。
3. **评级并回写**：复习档、下次到期、评级。

单概念超过 3 分钟没结论 → 判「忘记」，回写，继续下一个。不要卡在一个概念上。

## 五、交错与混合

一次复习必须跨模块：

- 至少覆盖 2 个不同模块的概念。
- 相邻两条不得来自同一模块（避免上下文惯性）。
- 每个概念只问 1 题，不连问。

## 六、异常处理

| 现象 | 处理 |
|---|---|
| 同一概念连续 3 次「忘记」 | 不是记忆问题，是前置有洞。退回查 `prereq`，重学对应前置，复习档重置为 0 |
| 复习档到 5 后仍「忘记」 | 降回 3 档，并检查是不是概念粒度太粗（把两个东西当一个记） |
| 30 天未复习 | **先抽查 1 题再定档**：不过则 -1 档（最低 0）并标「久未复习」；通过则只改到期日为今天 + 1 天。禁止不看就批量降档 |
| 整队列命中率 < 40% | 间隔放太长或概念太碎，整体 -1 档 |

## 七、review.md 结构

```markdown
| 概念 | 模块 | 复习档 | 上次评级 | 上次复习 | 到期日 |
|---|---|---|---|---|---|
| 闭包捕获 | M02 | 2 | 熟练 | 2026-10-30 | 2026-11-06 |
```

规则：
- 到期日只写日期，不写时间。
- **日期禁止心算。** 先取当天再加减，可直接复制：

```bash
TODAY=$(date +%F)                                   # 今天
date -d "$TODAY + 7 days" +%F                       # Linux / Git Bash 加 7 天
python -c "import datetime;print(datetime.date.today()+datetime.timedelta(days=7))"   # 跨平台兜底
```

- 手算已实测出过错：6 条里错 2 条（把复习前的档填进了「复习后」列）。凡写出到期日，必须能用上面的命令复现。
- `review.md` 只负责调度，不承担掌握度职责；掌握度看 `mastery.md`。

## 八、复习预算

- 单次会话复习不超过 12 条（硬上限）；剩余时间推进新内容。只复习不前进 = 停更。
- 每日到期数 > 20 时，降低新概念入队速度（每课最多入 3 个新概念）。
- 备考模式例外：允许单次全量复习，但必须轮换顺序。
