# 09 · 知识图谱总览（流程 A 第 3 步末）

大纲回答「学什么、什么顺序」，图谱回答「这些知识点之间是什么关系、每个点到底是什么」。
缺了图谱，学习者拿到的是一串待办；有了图谱，才知道自己站在网的哪个位置。

## 1. 什么时候出，写到哪

| 项 | 值 |
|---|---|
| 触发 | 大纲被用户确认后、出第一课之前（流程 A 第 3 步末） |
| 产物位置 | `study/<topic>/graph.html`，**topic 根目录下**，与 `syllabus.yaml` 同级（不是 `reference/`，那里只放速查件） |
| 数据 | `syllabus.yaml` 每模块下新增 `concept_cards`（6 个内容字段） |
| 呈现 | `study/<topic>/graph.html`（单文件、离线可开、可打印），照 `templates/graph.template.html` |
| 回填 | 每出一课，把该课概念的 `assumption` / `first_principle` / `plain` / `extend` 补实，图谱页同步更新 |

**不与铁律 2 冲突**：调研在出大纲之前已完成，图谱是调研结果的结构化表达，不是新的知识生产。
图谱页里写不出内容的字段，写「待补 + 为什么缺」，不许编。

## 2. 概念卡的六个字段（写在 `syllabus.yaml`）

**口径（唯一说法）**：每张卡 **6 个内容字段**（`name` 之外）；
再算上 **2D / 3D 两张图**，即铁律 18 说的 **八项**。

> 早期曾把 `name` 也算作一个「内容字段」而说成 7 个，已废弃。凡见旧说法一律按本节理解。

`concepts` 字符串列表保持不变（它是粒度与覆盖度的基准）；`concept_cards` 与它并列，
**两者概念名集合必须完全一致**，多一个少一个都算不一致。

```yaml
concept_cards:
  - name: "冷却时间"
    prereq: ["成型周期"]          # 概念级前置（可跨模块），无则写 []
    related: ["模具温度"]          # 相关但非前置：互相影响、常一起用、易混淆
    assumption: "前提是熔体在模内已充满并进入保压；若充不满，谈冷却时间没有意义"
    first_principle: "热传导 Fourier 定律：散热速率 ∝ 温差 × 接触面积 / 壁厚，壁厚平方级影响冷却时间"
    plain: "就像一大块冰和小块冰谁化得快——不是重量差一倍，是厚度差一倍时间差四倍"
    extend: "随形冷却水路、铍铜镶件、模温机选型；往熱流道与模流分析延伸"
```

每个字段的合格判据（写不出就是没想清楚，不许留空或用「同上」糊过去）：

| 字段 | 合格判据 | 常见糊弄 |
|---|---|---|
| `prereq` | 写概念名；跨模块的前置也允许；确实无前置写 `[]` | 把整模块写进来、写「无」而不解释 |
| `related` | 至少 1 个同类概念；说清是「互相影响 / 常一起调 / 易混淆」里的哪一类 | 把 related 写成 prereq |
| `assumption` | 一句「前提是 ___；不成立时会怎样」 | 只写「假设理想状态」 |
| `first_principle` | 追到一个不再追问为什么的定律/守恒律/定义，并写出推导方向 | 停在「经验上就是这样」、只复述结论 |
| `plain` | 用一个生活类比讲给外行，类比要**对齐机制**而不是只对齐表象 | 类比与机制无关（「就像开车」） |
| `extend` | 至少给一个「学完这个可以往哪走」，指向具体技术/章节 | 写「深入学习」 |

**断言三级同样适用于概念卡**：字段值里写判断性内容时，在括号里标注级别，
如 `assumption: "...（建议·单源）"`、`first_principle: "...（推断：若 X 则本条不成立）"`。
不另设 `evidence` 字段——级别跟着值走，避免又多一个要同步的列表。

## 3. 图示：图谱页讲结构，课内讲机制（两处都要，但画的东西不同）

> **先读 `11-visual-grammar.md`**：图面语法（什么时候不该画 / 复杂度预算 / remove test /
> 反模式 / 无障碍契约 / 手机宽）对**所有图**生效，本节只补「课内机制图」的特有部分。

| | `graph.html` | 课内 `lessons/*.html` |
|---|---|---|
| 画什么 | **结构**：前置/相关、概念在体系里的位置 | **机制**：这条规律为什么成立 |
| 形态 | 依赖图 + 每概念一张卡片图 | **坐标图**：横纵轴是真实物理量，曲线/曲面表达因果 |
| 数量 | 每概念 2D + 3D 各一 | **每课至少 2D 一张 + 3D 一张** |
| 标记 | — | `data-fig="2d"` / `data-fig="3d"`（可机检） |
| 硬要求 | 全内联、无外链 | 同左；且必须有**坐标轴 + 轴标签**，并标注「示意，不按比例，不含数值」 |

**课内的图不是图谱页那张的复制**：图谱页回答「它和谁有关」，课内的图回答「为什么必须这样做」。
例：讲「保压有上限」，图谱页画的是「保压」与「冷却时间」之间的连边；
课内画的是「保压时间 → 制品重量」曲线的平台段，以及它右侧那片无效区。

不画坐标图的课，只算「列出了结论」，不算「讲清了机制」。三张以上堆图同样不行——
一张图要能回答一个具体问题，答不出就是在装饰。

**每课图数上限 5，单图节点 ≤9、连线 ≤12、焦点 ≤2**（`11` §3）。超了就是这一课塞了不止一个能力点，该拆课。

- **2D 图示**：内联 SVG。画关系与结构（流程、对比、剖面、参数曲线）。
- **3D 图示**：内联 SVG **等距（isometric）投影**，或纯 CSS `transform: rotateX/rotateY` 的小部件。
  用来表示空间结构、层叠、体积关系。

硬约束（与「单文件离线可开」冲突时的处置）：

- **禁止外链 Three.js / 任何 CDN 的 3D 库**——外链一断，图就没了，课也不离线了。
- **禁止外链图片**（`src="http..."`）；图必须内联（SVG 直接写进 HTML，或 `data:` 内联位图）。
- 做不到真 3D 就用等距 SVG，这本身就是达标的 3D 图示，**不算降级，不用额外声明**。

### 3.1 三种容易含糊的情况（明确到可判定）

| 情况 | 规定 |
|---|---|
| 同一对概念**既在 `prereq` 又在 `related`** | 只画**实线前置**，不重复画虚线；卡片里两类都写出来。前置优先，因为「必须先学」的信息量更大 |
| 图注 / 图示里出现**无一手来源的数值** | 标「（数值待核验）」并在 `coverage_gap` 记一条，写明去哪核验。**不许因为「图里看起来专业」就写死数字** |
| 处于**无来源环境**（不联网、无一手材料） | 断言级别标「（待核验：去哪查）」，这是第三档的变体；不要因为标不了「单源」就干脆不标 |

### 3.2 九种图型：先选型，再画（课内图专用）

每张课内图必须先填得出这句话，填不出就不许画：

> **【这张图回答】一个问题。** 因为 机制，所以 结论。

这句话写进 `figcaption`；**问题本身**写进 `<figure data-q="...">`（可机检）。

**先判类型**：这条结论是「连续量之间的函数关系」还是「离散步骤」？
连续量再看有几个自变量——1 个 → 曲线族；2 个 → 曲面。离散量 → 流程/树/对比。

| # | 图型 | 回答的问题 | 有现成配方吗 | 反模式 |
|---|---|---|---|---|
| 1 | 坐标曲线 | 一个量随另一个量怎么变？ | `Fig.line()` 打底 | 不给轴标签，只画趋势 |
| 2 | 平台/饱和曲线 | 到哪一点之后再加投入就没用了？ | `plateau()` | 标了平台却不标拐点位置 |
| 3 | 交叉窗口 | 两个相反要求在哪里共存？ | `window()` | 只画一条线（那就不存在窗口） |
| 4 | 响应曲面（3D） | 两个变量一起变，结果怎么变？ | `slices()` 近似 | 画成装饰性 3D 饼图；不给切片 |
| 5 | 梯度/衰减曲面（3D） | 某量沿某方向为什么越来越弱？ | `slices()` | 把 3 个变量硬塞进 2D |
| 6 | 剖面/层叠 | 内部从外到内是什么样？ | 手写 | 画写实透视图（信息反而更少） |
| 7 | 流程 / 状态机 | 有哪几步，顺序能不能换？ | 手写 | 用流程图表意「并列关系」 |
| 8 | 对比条 | A 和 B 差多少？ | 手写 | 长度与数值不成比例 |
| 9 | 层级树 / 依赖图 | 谁是谁的前置？ | 手写 | 画成放射状导致连线交叉 |

**配方覆盖到哪，必须说清**：`plateau()` / `window()` / `slices()` 三个配方，加上 `Fig.line()` 打底，
能直接产出图型 1/2/3，图型 4/5 用 `slices()` 近似。**图型 6/7/8/9（剖面、流程、对比条、层级树）要手写坐标**
——手写时仍须满足下面的硬规范，并且**不要去找不存在的函数**（`flowchart()`、`tree()`、`bar()` 都没有）。

`slices()` 的纵深轴标签**默认会被推到轴的外侧，但仍可能与某条曲线相撞**——它是唯一一处「库替你决定标签位置」的地方。
撞了就传 `paxis_at=(x, y)` 显式指定，不要指望默认值。

**明确不做**：装饰性示意图、写实剖面、3D 爆炸图。它们增加认知负荷但不增加信息（Mayer 一致性原则）。

### 硬规范（课内图）

必须：

- 横纵轴各有轴标签；3D 图三个轴都要标
- 一个视觉焦点（红点 / 高亮带 / 加粗），且它对应 caption 的关键句
- 标注「示意，不按比例，不含数值」——除非真的按数据画
- 字号 ≥ 11px；无障碍按 `11` §7 的四条**唯一写法**（`role="img"` + `aria-labelledby` → 前缀化的 `<title>`/`<desc>`，`<title>` 是首子元素）
- 标签直接贴在被标注物旁（**空间邻近**），不许「图上编号 + 角落图例」

禁止：渐变、阴影、发光、`filter`、图例分离、**超过 3 个色相**、caption 里写「如上图所示」。

> 颜色按**色相**计，不按 hex 值计：同一色相的不同明度算一种，灰阶（轴/标签/示意声明）不计入。
> 这样「两条代价曲线 + 一个焦点带 + 坐标轴」才可能同时满足——真机实测这条按 hex 数会直接互斥。

### 坐标不要手算

横纵坐标换算、曲线路径、切片偏移这几件事最容易出错（实测 6 张图抓出 5 处压线/裁切）。
用 `scripts/kbfig.py`（纯标准库，无依赖）：把数据点丢进去，它算好像素与路径，**你只决定标签放哪**。

```bash
python scripts/kbfig.py --demo out.html    # 生成 4 张样例（图型 2/3/4/5），照它改数据即可
```

**标准用法（必须按这个顺序，否则 `plateau/window/slices` 会报 `AttributeError`）**：三步——①先 `Fig(...)` 建画布；②把画布 `f` 传给配方函数（它们**原地修改 `f` 并返回它**）；③用 `f.svg(...)` 取 SVG，再交给 `figure(...)` 包成带 `data-fig/data-q` 的 `<figure>`。

```python
import sys; sys.path.insert(0, "scripts")
from kbfig import Fig, plateau, figure

f = Fig(xlab="保压时间 t →", ylab="制品重量 / 关键尺寸")
plateau(f, [(0, .05), (.18, .55), (.36, .9), (.62, .93), (1, .93)],
        knee=.36, knee_label="浇口冻结 t_f",
        band_sub="补料通道已断 → 只增加周期，不增加料")
html = figure(
    f.svg("平台曲线", "到拐点后补料通道断开，再加周期不增料"),
    "为什么保压时间到某点后不再有用？",          # q 必须是问句
    "平台曲线：越过拐点只增周期不增料。")         # caption 不写「见图」
# html 即一段合法 <figure data-fig="2d" data-q="...">…</figure>，贴进 lesson 即可
```

`window(f, rise, fall, lo, hi)`、`slices(f, curves)` 用法同构：`f` 永远是同一个 `Fig` 实例。

**降级**：环境没有 Python → 照已有课里的图**结构照抄、标签重摆**，仍要满足上面硬规范。

## 4. 图谱页长什么样（`graph.html`）

1. 顶部一张 **2D 图谱**：节点 = 概念，实线箭头 = 前置，虚线 = 相关，按模块分色分区。
2. 下面每个概念一张卡：`前置 / 相关 / 前提假设 / 第一性原理 / 通俗说明 / 扩展` **各占一行** + `2D / 3D` 两张图。
3. 卡片按模块分组，与 `syllabus.yaml` 顺序一致。
4. 已上过的概念标出掌握档（读 `mastery.md`），没上的留空——**图谱同时是进度视图**。

## 7. 降级

| 缺什么 | 怎么办 |
|---|---|
| 画不出 3D | 用等距 SVG（达标，不声明降级） |
| 概念太多（>40）图谱画不下 | 分模块画多张图，首页只放模块级图 + 链接 |
| 图示画不完 | **任何规模都允许写可复用的绘制脚本批量生成，这属于常规手段，不是降级**（照抄同一张占位图才是糊弄）；仍做不到则按 `core` 集合降级，并写明「本次覆盖 X/N，跳过哪些」 |
| 某字段确实查不到 | 写「待补：<查什么、去哪查>」，在 `coverage_gap` 记一条，**不许编** |

## 8. 反模式

- **图谱画成目录**：只有层级没有依赖边，等于把大纲重抄一遍
- **related 写成 prereq**：把「相关」全画成箭头，图谱变成一张全连接的网，没有信息量
- **第一性原理只复述结论**：写「因为热传导」但没追到 Fourier 定律
- **类比不对齐机制**：「就像开车」这种只对齐了「需要操作」这一个表象
- **图外链 CDN**：当下能看，离线就白图
