# 错因本

只记**错因**，不记题目原文。同类错误第二次出现时，说明是前置有洞，不是粗心。

## 错因分类

| 类 | 判据 | 对策 |
|---|---|---|
| 概念混淆 | 把 A 当成 B | 出对照题，加反例 |
| 边界不清 | 知道大意但不知道适用范围 | 出极端条件题 |
| 前置缺失 | 卡在更基础的一步 | 回退补前置，别在此处硬练 |
| 流程遗漏 | 步骤记得但漏一步 | 做检查清单，不重讲原理 |
| 表述不清 | 心里懂但说不出来 | 费曼练习：讲给外行听 |
| 粗心 | 会但看错题 | 不改知识，改答题习惯 |
