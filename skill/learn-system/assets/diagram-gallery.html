S8 条形

复制时保留 role / aria-labelledby / <title> 三个属性，改 slug 前缀避免同页撞 id。
用法：找一张与你要讲的关系最接近的，照抄结构、换标签、按数据改坐标，不要从零算像素。
与 09 §3.2 的九种机制图（坐标曲线类）互补：那些讲「为什么」，这八种讲「有什么 / 在哪层 / 多少」。
