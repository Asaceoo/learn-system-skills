## 中文备注
- **一句话**：把「学完一个领域」做成可追踪的工程——前置依赖大纲 + 单点 HTML 课 + 概念级掌握度 + 复习队列，四件套同时在线。
- **适用场景**：要跨多轮推进、想知道自己学到哪、哪里薄弱；要可复习的速查件而不是聊天记录。
- **类别**：学习 / 教学
- **注意**：本 skill 是控制层，不重复造重活。单概念可视化、整域手册、交互课件分别**建议**切到 visual-knowledge-tutor、knowledge-handbook-builder、teachany——但那种跨 skill 委派并不可靠，所以本 skill 自带纯文字兜底。

# 体系学习控制器

## 路径解析（先读这段）

两类路径，解析基准不同，混淆会把文件写错地方：

- `references/*.md`、`templates/*` → **本 skill 目录**（`~/.workbuddy/skills/learn-system/`）
- `study/<topic>/*`、`./lessons/`、`./assets/` → **当前工作目录**（触发本 skill 的地方）

模板用法：先读 `templates/<x>.template.*`，填好后写到 `study/<topic>/<x>`。不要改模板本身。
已有课题可以不在 `study/` 下：**当前目录同时有 `syllabus.yaml` + `mastery.md` 即视为 topic 根**，不要硬套 `study/<topic>/`。

## 这是什么

四层，每层都有落盘状态：

- **目标** `MISSION.md`：为什么学。每课都要能回答「这服务于哪条目标」
- **体系** `syllabus.yaml`：学什么、什么顺序、前置依据、每模块验收
- **教学** `lessons/*.html`：一次一个点，讲完立刻可复习
- **掌握** `mastery.md` + `review.md`：到什么程度、什么时候该复习

聊天是入口，文件是事实。

## 与既有 skill 的分工

只做「跨多轮 + 要知道学到哪」。分工表与兜底见 `references/07-routing.md`；委派不承诺自动调用，切不成就自己做完。判断顺序：有没有这需求，有 → 本 skill。

## 铁律

全程生效。被要求跳过时先说清代价，再按用户意愿执行并记录偏离。

1. **一次只产出一课。** 出完停下等反馈，绝不批量。
2. **调研先于出课，且教材/标准锚定。** 基准怎么选见 `references/06-sources.md`。找不到来源标「待核验」，不许编。**调研是 topic 级的：开课时做一次**；后续课引用来源区外的新来源，须先补录 `resources` 再引用。
3. **断言分三级。** 事实（带小节级来源锚点）/ 建议（标明是建议）/ 推断（写出可推翻条件），不许混写。
4. **覆盖度要验收。** 每个 `concepts` 必须出现在某课正文或速查件；与教材目录做差集，教材有而没讲的写进 `not_covered` 并给理由；每模块写「不覆盖什么」。
5. **开课前必须有 MISSION**：为什么学 / 什么算成功 / 不学什么（可留待大纲确认时补）。
6. **开课前必须有大纲**，用户确认后才出第一课。
7. **每模块必须有前置依据**：写一句「缺了它你会卡在 ___」。写不出就不是硬前置，移到 `nice_to_have`。
8. **M01 完成时必须复审大纲**：学完第一模块才有判断力，此时强制问一次「前置假设还成立吗」。
9. **进模块前校验前置**：`prereq` 各模块 `core` 列表里的概念须 ≥ L3；没写 `core` 的，按该模块 `concepts` 的前两个判定。
10. **每课结束必须更新 `mastery.md`**。用户未答自检时把本课概念标为「已上未评」并写进变更日志；没留任何痕迹的一课才等于没上。
11. **判定要证据并写明判定方**。只有 `references/04-mastery.md` 证据表里的类型可用，表外不得升档。
12. **自评必须写得出「我能独立做到 ___」**，写不出按 L2 封顶。
13. **出题遵守零提示**，见 `references/03-assessment.md`。
14. **复练不许重问原题**，必须换语境。
15. **日期禁止心算**：先用 `date +%F` 取当天再加减。手算已实测出过错。
16. **不往个人目录根下写文件**：`~/Desktop`、`~/Downloads`、`~`、`/` 一律不建，退回 `~/Documents/learn-system/<topic>/`。
17. **无证据不得升档，也不得为了让表格好看而给档位。** 用户未答自检时保持「已上未评」。与铁律 10 冲突时以本条为准。
18. **每个概念须有图谱六字段 + 2D/3D 两图，缺一不算覆盖**，细则见 `references/09-knowledge-graph.md`。

## 状态模型

默认工作目录：当前项目下 `study/<topic>/`。泛目录或系统目录按铁律 16 兜底。

```text
study/<topic>/
├── MISSION.md              # 起步必建
├── syllabus.yaml           # 起步必建（resources 写在文件末尾注释区）
├── mastery.md              # 起步必建（唯一恢复入口）
├── review.md               # 起步必建
├── lessons/NNNN-*.html     # 起步必建
├── reference/*.html        # 第 2-3 课起按需
├── mistakes.md             # 按需：同一概念累计 2 次错
├── learning-records/       # 按需：目标或大纲变更
└── assets/                 # 按需：第二课要复用样式时才建
```

**起步只建 5 个。** 其余按触发条件创建，不要一次铺满。

### 恢复入口（唯一）

`mastery.md` 顶部固定三行，新会话只读这三行就能知道自己在哪：

```markdown
## 当前状态
- 当前模块：M02
- 下一课：0003 冲突标记三段怎么读
- 到期复习：0 条（队列 3 条，下次到期 2026-11-01）
```

不要把恢复信息散到别的文件。**口径**：「到期复习」= **今天**到期数，必须与 `review.md` 的「今天到期 N 条」一致；队列总数写在括号里。

**新会话怎么找到它**：先扫 `study/*/mastery.md`；唯一命中就直接用；多个 → 列出让用户选；一个都没有但当前目录同时有 `syllabus.yaml` 和 `mastery.md` → 当前目录即 topic 根；都没有 → 走流程 A。

### 两个刻度不要混

- `mastery.md`：**掌握档 L1-L5**，表示学到什么程度
- `review.md`：**复习档 0-5**，表示复习间隔

两者不通约、不互相换算。同一概念两处都要有行。

### 接管已有进度

若当前目录命中以下 **2 个及以上**信号，**且没有 `syllabus.yaml`**（有则为本 skill 自己进度，直接继续），先问一句「接管 teach 的进度，还是另开 `study/<topic>/`」：

- `lessons/*.html` 存在
- `MISSION.md` 存在
- `learning-records/` 存在

只问这一句。选接管则把 teach 的 `learning-records/`、`lessons/` 视为已有资产，不重复生成。

## 主流程

### A 开课

1. 读 `MISSION.md`；缺失 → 问三件事：为什么学、什么算成功、每周几小时。**用弹窗卡片**（`show_widget`，规范先取 `widget_guidelines`）：每问 2-4 个可点选项、末尾汇总行 + 确认按钮；照 `templates/intake-dialog.template.html` 画，细则见 `references/08-intake-dialog.md`。模式并入第 3 题，不做第四问。
2. **深度调研**（`references/06-sources.md`）：定基准（教材/官方文档/现行标准）→ 拿 2 个独立目录 + 1 份课程标准 → 关键结论做 ≥2 源交叉 → 记版次年份。结果写进 `syllabus.yaml` 的 `anchor` 与 `resources`。主源不足 3 条可开链接时不得出课。
3. 出大纲：按 `references/01-system-design.md` 拆 3-12 模块（推荐 5-12），每个模块必须有 `prereq`、前置依据、概念、产出物、预算、验收。用 `templates/syllabus.template.yaml`。**大纲确认后出图谱**（`references/09-knowledge-graph.md`）：每概念补七字段 + `graph.html`（2D、等距 3D）。
4. 用户确认大纲后，出一课。走流程 B。

### B 出一课

1. 读 `mastery.md`（含三行状态）+ `syllabus.yaml` + 上一课反馈，定这课教什么：前置已过、属当前模块、在最近发展区内。上一课自检未作答**不影响继续出课**，但本课必须在 `mastery.md` 留痕（铁律 10 / 17）。
2. 读 `./assets/` 已有组件（图片、数据表），能复用就复用。**样式一律内联**，不抽 `assets/lesson.css`——抽出来就破坏「单文件离线可开」。
3. **先落状态，再写正文**（顺序是硬约束：长 HTML 写完后最容易漏收尾，先占位就不怕漏）：
   - `mastery.md`：本课概念写行——**骨架行已存在时更新该行，不要插重复行**；无证据写「已上未评」；刷新顶部三行；变更日志记一条
   - `review.md`：新概念入队，复习档 0，到期 = 今天 + 1 天
   - **概念名必须与 `mastery.md` 完全一致**，不得自造同义名；一个概念拆多课时仍只占一行；粒度以 `syllabus.yaml` 的 `concepts` 为准，正文不得自行拆并
4. 写 `lessons/NNNN-<name>.html`：单文件、离线可开、可打印，结构按 `templates/lesson.template.html`。命名：课用中文概念名（如 `0003-冷却时间.html`），速查件 `<概念名>速查.html`。
5. 接导航：本课「上一课」指向 NNNN-1，并把上一课的「下一课」改成指向本课——**两边都要改**。**下一课尚未产出时写纯文本「下一课：NNNN 名称（待产出）」，不要写 href**——写 href 就是断链。
6. 课内必含：一个能力增量、一个立即可做的练习、3-5 题零提示自检、一条主源链接、一个「问老师」入口。
7. 只在压出可长期回看的知识单元（对照表/术语/决策路径）时才写 `reference/<概念名>速查.html`；纯概念讲解课**可以不写**，课内就**不要链速查件**。**写了才允许链**。
8. 用户答完自检后，回填掌握档（L1-L5）+ 证据 + 判定方。答之前保持「已上未评」，不自评升档（铁律 17）。
9. **交课前逐项打勾**——每条都要贴**落盘证据**（改前 → 改后的实际行，或 `date`/`grep`/`ls` 实际输出）。只写「已完成」不算：
   - [ ] `mastery.md`：本课概念已写行、顶部三行已刷新、变更日志已记
   - [ ] `review.md`：新概念已入队
   - [ ] 导航：本课「上一课」与上一课「下一课」两边都改了
   - [ ] 概念名与 `mastery.md` 完全一致
   - [ ] 本课 HTML 里所有 `href` 都真实存在（`ls` 核对）；若**上一课**有断链：href 降级为纯文本并上报，**不要顺手补写文件**（铁律 1）
   - [ ] 已停下等反馈，没有顺手出下一课
   - [ ] **上面每条都贴了落盘证据**
   回复时把这 7 项连同证据列一遍；未打勾要说明原因。
10. 当前模块的**最后一课**上完时，执行铁律 8（复审大纲）。触发点是模块完成，不是第一课完成。
11. 停下，告诉用户下一课是什么，等反馈。**不要直接出下一课。**

### C 复习

进入时**第一句先报「今天到期 N 条」**，再问是否开始。

1. 读 `review.md`，筛 `到期日 <= 今天`，按「逾期最久 → 复习档最低 → 上次忘记优先」排序，最多 12 条。
2. 按 `references/05-review.md` 出抽问题，不重讲。
3. 评级三档：忘记 / 勉强 / 熟练，改复习档与下次到期。
4. 评「忘记」的概念计一次错。**同一概念累计 2 次错**才创建 `mistakes.md` 并记入；不足 2 次先记在 `mastery.md` 该行备注。
5. 回写两个文件，报本次升降。

### D 测掌握度

1. 读 `mastery.md`，选目标模块全部概念。
2. 出跨概念混合题（覆盖记忆/理解/应用/迁移），不是逐概念各一题。
3. 判分后按 `references/04-mastery.md` 重定掌握档，写证据与判定方。
4. 输出：掌握档表 + 三个最薄弱点 + 各自补强任务 + 复测时间。

### E 调整与停更

触发：目标变了、进度落后、某模块连续两课无进展。

- 改 `syllabus.yaml`，并在 `learning-records/` 记「改了什么、为什么、影响哪些已完成模块」。目标变更必须先改 `MISSION.md` 并确认。
- **停更三档**（以成功判据「一个领域走到 M05」为准，判定日 = 超过预期时长）：
  - 逾期 1 周 → 砍模块：改 `syllabus.yaml`，删掉或合并模块，记一条 learning-record
  - 逾期 3 周 → 改判据：降为更少模块，写明理由，更新 MISSION
  - 逾期 6 周 → 判定失败：整体移入 `_archive/`，本 skill 不再维护该主题。**不要再假装还在学**

## 降级

- 缺联网检索 → 本地资料 + 标「待核验」，告知哪些结论未核验
- 缺写文件 → 在对话里给完整内容与路径请用户落盘，告知本应写入哪些
- 缺 HTML 渲染 / 可视化 → 退化为 Markdown 课，图示用手写 SVG 或 ASCII，不跳过；告知已退化
- 缺弹窗 / 交互能力 → 退化为三行纯文本三问（每问带选项编号，用户回编号即可），不跳过；告知已退化

降级允许，跳过不允许。

## 反模式

出现任一，立即停手纠正：

- 用「已经讲过了」代替「考过了」
- 掌握度长期不更新，或档位靠感觉给
- 一课塞多个能力点，超出工作记忆
- 引用来源是自己编的书名或链接
