# learn-system 用户手册

> 版本：v0.6.1　|　面向：使用这个 Skill 学习的人　|　技术细节见 `TECHNICAL.md`

---

## 1. 它是什么

一个让你**把「学完一个领域」做成可追踪工程**的 Skill。它不生产知识本身，它生产的是：

- 一份带前置依赖的大纲（学什么、什么顺序、为什么这个顺序）
- 一节节可打印的 HTML 课（每节带来源锚点、自检题、可查证三条）
- 一张概念级掌握度表（哪个概念学到 L 几，凭什么）
- 一张复习排期表（什么时候该复习什么）

打个比方：它像请了个私教，但教案本、成绩单、复习闹钟都放在**你自己家的文件夹**里。换会话、关电脑、隔一个月回来，私教（AI）可以忘，文件夹不会忘。

**它做不到**的：保证知识正确。它能做到的是——让「这课可不可信」变成你 30 秒内能自己判断的事。

## 3. 第一次用：你会经历什么

### 第 1 步：三个问题（弹窗）

| 问 | 代号 | 为什么问 | 怎么答 |
|---|---|---|---|
| Q1 为什么学 | A1 工作马上用 / A2 转岗求职 / A3 兴趣通识 | 决定剪掉什么 | 「工作要用，要能跟供应商对话」比「想了解一下」有用得多 |
| Q2 什么算成功 | B1 做出东西 / B2 通过考试 / B3 讲明白 | 这是验收标准 | 要能验收：「给一个缺陷说出 2-3 个成因」√；「了解注塑」× |
| Q3 怎么学 + 每周几小时 | C1 标准 / C2 备考　·　D1 每周1-3 / D2 4-6 / D3 7+ | 决定模块数与周期 | 两件事一起选；小时数填真实值，填多了只会导致大纲做不完 |

怎么提交：

- 点卡片上的选项，最后一行会汇总成 `A1 B3 C1 D2` 这样的短串，点**「确认，开课」**直接发回对话
- 也可以在对话框里手打这串代号，效果一样
- 有硬截止日期（考证、面试）就选 C2 备考，会切成高频测验节奏

答完会立刻写进 `MISSION.md`，**下次开课不会再问这三件事**。

几种特殊情况：

- **只选了一部分** → 用已选的开课，缺项写「未定」，不会卡住等你
- **一直不点** → 直接说「直接开始」，按默认值（A3 / B3 / C1 / D2）开课，随时可改
- **回复的是自己的话**而不是代号 → 它会先把提取出来的三件事复述一遍，确认后才落盘
- **你的平台没有弹窗** → 退化为三行纯文本三问，回编号即可

### 第 2 步：它去调研，然后给你大纲

它会按领域类型选知识基准：

| 你的领域 | 基准 |
|---|---|
| 稳定学科（数学、材料、工艺、法律） | 2 本教材目录 + 课程标准，取并集 |
| 快变领域（AI、框架、工具链） | 官方文档目录 + 原始规范 |
| 强监管（建材、医疗器械、食品） | 现行 GB/ISO 标准 + 你的一手材料 |

然后出 3-12 个模块（推荐 5-12），每个模块都写明：**缺了前置你会卡在哪一步**、这个模块对应教材哪几章、这个模块**不覆盖**什么。

### 第 3 步：你确认，它才出第一课

大纲没确认就不出课。这一步别跳过——大纲错了，后面五个模块都建在沙子上。

### 第 4 步：一课一课推

每课出完就停，等你反馈。**不会一口气给你 10 课。**

## 4. 五条流程，你能怎么用

### A 开课

```
系统学 <领域>
入门 <领域>
我想体系学一下 <领域>
```

产出 5 个文件，等大纲确认后出 0001。

### B 出一课

```
继续 / 下一课 / 上一篇
我读完了，<某段>没懂
```

每课包含：一个能力增量、一个 5 分钟能做完的练习、3-5 题零提示自检（点了立刻判分）、一条主源链接、一个「问老师」入口、课末三条可查证断言 + 易过期清单。

**自检一定要答。** 不答的话，掌握度会一直是「已上未评」，仪表盘永远是 0，进下一模块时还会被前置门槛卡住。

### C 复习

```
复习 / 该复习什么
```

它第一句会报「今天到期 N 条」。复习是**抽问，不是重讲**。你只需给三档评级：

| 评级 | 含义 | 结果 |
|---|---|---|
| 忘记 | 答不出或答错核心 | 复习档 -2，明天再来 |
| 勉强 | 答对但慢/犹豫/要提示 | 复习档不变，按当前间隔 |
| 熟练 | 快而准且能说清为什么 | 复习档 +1，间隔拉长 |

间隔：0→1天，1→3天，2→7天，3→16天，4→35天，5→75天。

### D 测掌握度

```
考考我 / 我学到哪了
```

跨概念混合题（不是逐概念各一题），覆盖记忆/理解/应用/迁移。判完输出：掌握档表 + 三个最薄弱点 + 补强任务 + 复测时间。

### E 调整与停更

```
太浅了 / 太难 / 赶不上 / 我太久没学了
```

停更三档（按成功判据「一个领域走到 M05」）：

| 逾期 | 处置 |
|---|---|
| 1 周 | 砍模块，改大纲，记一条 learning-record |
| 3 周 | 改判据（降为更少模块），更新 MISSION |
| 6 周 | 判定失败，整体移入 `_archive/`，不再维护 |

**有死亡条件，才不会变成第 14 个吃灰 skill。**

## 5. 文件说明

### MISSION.md

三件事：为什么学、什么算成功、**不学什么**。第三件最容易被忽略，也最重要——它是防止范围失控的闸门。

### syllabus.yaml

```yaml
topic:
  name: "注塑"
  goal: "学完之后，我能在 ___ 场景下，独立完成 ___，且达到 ___ 水平。"
  horizon_weeks: 6
  weekly_hours: 3
  started_at: "2026-10-31"    # 停更三档靠它算
  mode: standard              # standard | exam
anchor:
  type: textbook              # textbook | official | standard
  basis: "《书名》第 X 版目录 + 《书名2》第 Y 版目录 + 课程标准"
  cross_checked: 4            # 已交叉结论数
  single_source: 2            # 单源结论数（课内必须标「单源」）
  disputed: 1                 # 有分歧的结论（两说都写）
modules:
  - id: M01
    title: "能说出问题与边界"      # 动词短语
    prereq: []                  # 前置模块
    why_prereq: ""              # 缺了它会卡在哪一步（写不出就不是硬前置）
    concepts: ["概念A", "概念B"]
    core: ["概念A"]              # 前置校验只看这些
    deliverable: "一张对比表"
    budget_hours: 2.5
    check: "不看资料说出 ___"      # 验收证据
    not_covered: "本模块不覆盖 ___，原因是 ___"
    textbook_ref: "《书名》第 4 章 4.1-4.3"
    status: doing               # pending | doing | done
coverage_gap:                   # 与教材目录的差集
  - item: "教材第 6 章 浇注系统"
    decision: not_covered       # added | not_covered
    reason: "属模具设计职能"
resources:
  first_hand: []                # 级 0：你的厂内资料
  standard: []                  # 级 1：现行 GB/ISO
  primary: []                   # 级 2：官方文档
  textbook: []                  # 级 3：教材/课标
  secondary: []                 # 级 4
  tertiary: []                  # 级 5
  unverified: []                # 待核验
```

### mastery.md

| 列 | 填什么 |
|---|---|
| 概念 | 必须与 syllabus 的 `concepts` 完全一致 |
| 掌握档 | L1 知道 / L2 会用 / **L3 会改（分水岭）** / L4 会设计 / L5 会迁移 |
| 证据 | 至少两类，且至少一类是产出型；单一证据封顶 L2 |
| 判定方 | agent（客观可判题）或 自评（产出物/讲解/应用） |
| 备注 | 写不出「我能独立做到 ___」就按 L2 封顶 |

**顶部三行是唯一恢复入口**，新会话读这三行就知道自己在哪：

```markdown
## 当前状态
- 当前模块：M01（进行中）
- 下一课：0003 冷却时间
- 到期复习：0 条（队列 3 条，下次到期 2026-11-01）
```

### review.md

| 列 | 填什么 |
|---|---|
| 复习档 | 0-5，**记录复习后的档**（不是复习前） |
| 上次评级 | 忘记 / 勉强 / 熟练 |
| 到期日 | `date +%F` 取当天再加减，**禁止心算** |

### lessons/*.html

单文件、离线可开、`Ctrl+P` 可打印。区块：能力增量 → 正文（每节带来源锚点）→ 相邻概念对比 → 常见误区 → 动手练（折叠答案）→ 自检 → 风险标注 → 三条可查证 → 易过期 → 主源 → 导航。

## 6. 常见问题

**Q：为什么课出得这么慢，一次才一节？**
批量生成的课最容易把掌握度表刷成空的——那等于没学。两个停点（大纲后、每课后）是故意的。

**Q：我不答自检会怎样？**
可以继续出下一课，但掌握度会一直是「已上未评」，且进下一模块时会被前置门槛（≥L3）卡住。不会给你凭空升档。

**Q：「已上未评」是档位吗？**
不是。它是「还没评」的占位。铁律 17 明确：无证据不得升档，也不得为了让表格好看而给档位。

**Q：我的资料和网络来源冲突怎么办？**
以你的为准。级 0 一手材料（厂标、检测报告、工艺文件、老师傅经验）优先级最高——行业隐性知识根本不在互联网上。

**Q：能不能一次学两个领域？**
可以，各自一个 `study/<topic>/` 目录。新会话时若命中多个，它会列出来让你选。

**Q：换了电脑/目录变了怎么办？**
只要 `study/<topic>/` 在，`mastery.md` 顶部三行就能恢复。目录不在 `study/` 下也行——当前目录同时有 `syllabus.yaml` + `mastery.md` 就会被认作 topic 根。

**Q：我只想搞懂一个概念，不想建体系**
用 `visual-knowledge-tutor` 更合适。本 skill 的价值在「跨多轮 + 要知道学到哪」。

## 7. 三条使用纪律

1. **答自检。** 不答就没有掌握度，没有掌握度就没有复习调度。
2. **真去抽查那三条。** 课末「30 秒你能自己查证的三条」不是装饰，你不查它就只是一份排版好看的猜测。
3. **范围写小。** 「学木门」不可验收，「学木门含水率与变形的关系」可验收。`not_covered` 写得越具体，漏得越少。
