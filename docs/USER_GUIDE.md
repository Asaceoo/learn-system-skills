# learn-system 用户手册

版本：v0.7.4　|　面向：使用这个 Skill 学习的人　|　技术细节见 `TECHNICAL.md`

---

## 1. 这是什么

一个**学习控制层**。它不负责「讲」，负责四件事：

1. **学什么** —— 从教材目录和课程标准里长出大纲，不是凭感觉列
2. **什么顺序** —— 前置依赖写清楚，前置缺了会卡在哪也写清楚
3. **到什么程度** —— 掌握档 L1-L5，靠证据升，没证据不动
4. **什么时候复习** —— 复习队列按到期日调度，不重讲

它跟「讲解型」技能最大的区别：**它记得你学到哪了**，而且记在文件里，不在聊天里。

---

## 2. 它怎么记住你学到哪了

这是最容易出错的一步，规则写死：

- 扫**当前工作目录**下的 `study/*/mastery.md`，和兜底目录 `~/Documents/learn-system/*/mastery.md`
- **不向上级目录找**——否则在仓库或多项目目录下会误命中别人的课题
- 唯一命中直接用；**多个命中列表让你选**，不靠文件时间戳自己猜

为什么要在意这条：如果你曾经因为「别在桌面堆垃圾」被退到 `~/Documents/learn-system/`，下次在别的目录说「继续」，旧规则会找不到它、当成新课题重开。v0.7.3 修的就是这个。

## 3. 安装

```bash
# 推荐：解压 zip
unzip learn-system-v0.7.4.zip -d ~/.workbuddy/skills/
```

Windows 解压到 `C:\Users\<你>\.workbuddy\skills\`，确认路径是：

```text
~/.workbuddy/skills/learn-system/SKILL.md
```

装完在对话里说「我想系统学 注塑」即可触发。

## 4. 第一次用：你会经历什么

### 第 1 步：三个问题（弹窗）

开课时会弹一张卡，只有三问，每问几个可点选项：

| 问 | 代号 | 为什么问 | 怎么答 |
|---|---|---|---|
| Q1 为什么学 | A1 工作马上用 / A2 转岗求职 / A3 兴趣通识 | 决定剪掉什么 | 「工作要用，要能跟供应商对话」比「想了解一下」有用得多 |
| Q2 什么算成功 | B1 做出东西 / B2 通过考试 / B3 讲明白 | 这是验收标准 | 要能验收：「给一个缺陷说出 2-3 个成因」√；「了解注塑」× |
| Q3 怎么学 + 每周几小时 | C1 标准 / C2 备考　·　D1 每周1-3 / D2 4-6 / D3 7+ | 决定模块数与周期 | 两件事一起选；小时数填真实值 |

**怎么提交**：点选项 → 最后一行汇总成 `A1 B3 C1 D2` → 点「确认，开课」直接发回对话。
也可以在对话框手打这串代号，效果一样。

有硬截止日期（考证、面试）就选 **C2 备考**，会切成高频测验节奏。

答完立刻写进 `MISSION.md`，**下次开课不会再问这三件事**。

**几种特殊情况：**

- **只选了一部分** → 用已选的开课，缺项写「未定」，不会卡住等你
- **一直不点** → 直接说「直接开始」，按默认值（A3 / B3 / C1 / D2）开课，随时可改
- **回复的是自己的话**而不是代号 → 它先把提取出来的三件事复述一遍，确认后才落盘
- **你的平台没有弹窗** → 退化为三行纯文本三问，回编号即可

### 第 2 步：它去调研，然后给你大纲

按领域类型选知识基准：

| 领域类型 | 基准从哪来 |
|---|---|
| 稳定学科（物理、注塑工艺） | 教材目录 + 课程标准 |
| 快变领域（某框架、某产品） | 官方文档 |
| 强监管领域（食品、医疗、建材） | 现行标准（GB / ISO） |

它会给 **2 个独立教材目录 + 1 份课程标准**，关键结论做两源交叉，并标出：
- 哪些结论有两个以上来源互相印证
- 哪些只有单源（会在课里标「单源」）
- 哪些存在分歧（两说都会写出来）

然后出 **3-12 个模块的大纲**。每个模块必须有：

```yaml
- id: M01
  title: "能说出问题与边界"
  prereq: []                     # 前置模块
  why_prereq: ""                 # 前置依据：缺了它会卡在哪
  concepts: ["概念A", "概念B"]    # 概念清单（粒度基准）
  core: ["概念A"]                 # 进模块前必须 L3 的核心概念
  deliverable: "一张对比表"        # 本模块产出物
  budget_hours: 1.5              # 时间预算
  check: "不用材料，说出 X 与 Y 的两个差别"   # 验收题
  not_covered: "本模块不覆盖 ___，原因是 ___"  # 明确不教什么
```

### 第 3 步：知识图谱总览（本版新增）

大纲确认后、出第一课之前，它会出**知识图谱总览**——这是本版最重要的新增。

**为什么要这一步**：大纲告诉你「学什么、什么顺序」，但学的时候你常常不知道自己在整张网的哪个位置。图谱把这张网摊开给你看。

它会产出两个东西：

1. `syllabus.yaml` 里每个模块下的 `concept_cards`（数据）
2. `graph.html`（能看能打印的图）

**每个概念必须有八项**，缺一项不算覆盖（铁律 18）：

| # | 项 | 长什么样 | 合格判据 |
|---|---|---|---|
| 1 | 前置 | 「学它之前得先懂谁」 | 写概念名，可跨模块 |
| 2 | 相关 | 「和谁互相影响 / 常一起调 / 易混淆」 | 要和前置区分开：相关不是必须 |
| 3 | 前提假设 | 「前提是 ___；不成立会 ___」 | 不能只写「假设理想状态」 |
| 4 | 第一性原理 | 「追到某个定律/守恒律，然后这样推下来」 | 不能停在「经验上就是这样」 |
| 5 | 通俗说明 | 一个生活类比 | 类比要**对齐机制**，不是只对齐表象 |
| 6 | 扩展 | 「学完能往哪走」 | 指向具体技术/章节，不写「深入学习」 |
| 7 | 2D 图示 | 流程 / 对比 / 剖面 / 曲线 | 内联 SVG，不外链图片 |
| 8 | 3D 图示 | 等距投影的空间结构图 | 内联，**不用 Three.js**（断网就白图） |

`graph.html` 里能干什么：

- 看**依赖图**：实线箭头 = 前置，虚线 = 相关
- 点概念看**八项卡**
- 概念卡上带**掌握档**（读 `mastery.md`）——所以图谱同时是进度视图
- 浏览器「打印」直接出 PDF（已做 print 样式）

**如果概念很多**（比如 26 个，52 张图），它会写可复用的绘制脚本批量生成——手册明确允许，这不算降级。真做不到才按 `core` 集合降级，并会告诉你「本次覆盖 X/N，跳过哪些概念」。

**写不出来的时候**：第一性原理、前提假设查不到依据时，它会写「待补：<查什么、去哪查>」并在 `coverage_gap` 记一条，**不会编**。

### 第 4 步：第一课

一课只讲一个能力点，课里必有：能力增量 / 一个立即可做的练习 / 3-5 题零提示自检 / 一条主源链接 / 一个「问老师」入口。

HTML 单文件、离线可开、可打印。自检题点选项立刻判对错。

## 5. 五个流程怎么用

| 你说 | 走 | 发生什么 |
|---|---|---|
| 我想系统学 X | A 开课 | 三问 → 调研 → 大纲 → 图谱 |
| 继续 / 下一课 | B 出一课 | 先落状态再写正文，交课前 7 项贴证据 |
| 我读完了 | B 收尾 | 回填掌握档 |
| 该复习什么 | C 复习 | 先报「今天到期 N 条」 |
| 考考我 | D 测掌握度 | 跨概念混合题 |
| 太浅了 / 太难 / 赶不上 | E 调整 | 改大纲 |
| 太久没学了 | E 停更判定 | 逾期 1/3/6 周三档 |

### B 出一课里，它必须做的事

交课前会逐项打勾，**每一条都要贴落盘证据**（改前→改后的实际行，或 `date` / `grep` / `ls` 的实际输出）：

- `mastery.md`：本课概念已写行、顶部三行已刷新、变更日志已记
- `review.md`：新概念已入队
- 导航：本课「上一课」与上一课「下一课」两边都改了
- 概念名与 `mastery.md` 完全一致
- 本课 HTML 里所有 `href` 都真实存在
- 已停下等反馈，没有顺手出下一课

只写「已完成」不算打勾。

### C 复习的规则

- 进入第一句先报「今天到期 N 条」
- 按「逾期最久 → 复习档最低 → 上次忘记优先」排序，最多 12 条
- 只出抽问题，**不重讲**
- 评「忘记」计一次错；**同一概念累计 2 次错**才建 `mistakes.md`

## 6. 五个文件逐个说

### MISSION.md

```markdown
# MISSION
- 为什么学：A1 工作上马上要用（用户选定）
- 什么算成功：B1 能独立做出一个东西 —— 在 <场景> 下独立完成 <什么>，达到 <水平>
- 每周可投入：C1 标准　·　D1 每周 1-3 小时　·　预期 12 周，到期 2027-01-23
- 不学什么：不学设备维修（可留待大纲确认时补）
```

三个字段来源分明：用户选的标「用户选定」，系统给的默认值标「默认」。

### syllabus.yaml

最复杂的文件。关键片段：

```yaml
topic:
  name: "注塑"
  horizon_weeks: 6          # 由每周小时数换算，见下表
  started_at: "2026-10-31"  # 停更三档靠它算
  weekly_hours: 3

modules:
  - id: M01
    concepts: ["成型周期", "熔体温度"]     # 粒度基准
    core: ["成型周期"]                    # 前置校验只看这些
    concept_cards:                       # 铁律 18：六字段 + 两图
      - name: "成型周期"
        prereq: []
        related: ["冷却时间"]
        assumption: "前提是模内已充满；不成立时讨论周期没有意义"
        first_principle: "能量守恒 + Fourier 导热：散热速率 ∝ 温差 / 壁厚（推断：若壁厚分布不均，本条需修正）"
        plain: "就像一大块冰和小块冰谁化得快——不是重量差一倍，是厚度差一倍时间差四倍"
        extend: "随形冷却水路、模温机选型、模流分析"
        evidence: "教材A §4.2（事实）"
```

**`horizon_weeks` 怎么来**（不能凭感觉）：

| 每周小时 | 代号 | 取中位 | horizon_weeks |
|---|---|---|---|
| 1-3 | D1 | 2 | 12 周 |
| 4-6 | D2 | 5 | 5 周 |
| 7+ | D3 | 9 | 3 周 |

推导：目标 8 模块 × 2.5 小时 ≈ 20 小时，留 25% 给复习返工 → 25 小时；
`horizon_weeks = 25 ÷ 每周小时中位`，向上取整。大纲出来后按实际模块数重算。

**两条一致性规则**（审计会查）：

1. `concept_cards[].name` 的集合必须和 `concepts` **完全一致**，多一个少一个都算错
2. 概念级 `prereq` 必须**无环**能拓扑排序

### graph.html

知识图谱总览。单文件、离线可开、可打印、**无任何外链**。

结构：顶部依赖图（实线=前置，虚线=相关）→ 下面每概念一张卡（六行文字 + 2D/3D 两张内联 SVG）。

### mastery.md

掌握档 L1-L5。**唯一恢复入口**——新会话只读顶部三行就知道你在哪：

```markdown
## 当前状态
- 当前模块：M02
- 下一课：0003 冲突标记三段怎么读
- 到期复习：0 条（队列 3 条，下次到期 2026-11-01）
```

档位对照：

| 档 | 判据 | 能干什么 |
|---|---|---|
| L1 | 能认出来、能说出名字 | 看懂别人的表述 |
| L2 | 能解释是什么 | 复述，但换个场景就不行 |
| L3 | 能独立用在新场景 | 换个例子也能用对 |
| L4 | 能判断边界、知道何时不适用 | 能纠错 |
| L5 | 能教别人、能改造 | 能迁移到相邻领域 |

**没证据不给档位。** 自检没答就是「已上未评」，AI 不会自评升档（铁律 17）。

### review.md

复习档 0-5，数字越大间隔越长。**和掌握档不通约**：L3 不等于复习档 3，也不互相换算。

## 7. 常见问题

**Q：它讲的和我教材不一致怎么办？**
以你的教材/一手材料为准。告诉它「我教材上写的是 X」，它会按级 0（一手材料）优先处理，并把分歧记进 `coverage_gap`。

**Q：能同时学两个领域吗？**
能。每个领域一个 `study/<topic>/` 目录，互不干扰。

**Q：我在不同目录下都有学过的课题，它会不会搞混？**
不会。它只扫**当前工作目录**和 `~/Documents/learn-system/`，不向上级找；如果两处都命中，它会列出让你选，不会自己猜。

**Q：换了电脑 / 隔了两个月回来，它还认得我吗？**
认得。把 `study/<topic>/` 整个目录带过去，说「继续」即可。恢复入口是 `mastery.md` 顶部三行。

**Q：图谱为什么不能直接看到 3D 模型？**
因为 3D 库要联网加载，一断网整张图就白。等距 SVG 是离线可用的方案，效果是「立体示意」而不是可旋转模型。

**Q：概念太多了，图谱做不完怎么办？**
它会写可复用的绘制脚本批量生成（允许）。真做不到才降级，并且会明确告诉你覆盖了哪些、跳过了哪些。

**Q：为什么每课只讲一个点？**
超出工作记忆的课等于没上。要一次讲三个点的，切 `visual-knowledge-tutor`。

**Q：能导出成文档给同事看吗？**
课和速查件都能直接打印。要成体系的手册，切 `knowledge-handbook-builder`。

## 8. 三条纪律

1. **聊天里不留状态。** 你说的每句话都可能丢，只有文件不会。
2. **答完自检才给档位。** 没答就是「已上未评」，这是为了防止自评虚高。
3. **日期一定用命令算。** `date +%F`，不心算——手算已实测出过错。

## 9. 更新与回退

```bash
python build.py --bump patch    # 递增版本 + 同步文档 + 部署到已装副本 + 打包
python learn-system-audit.py    # 140 项自检，退出码非 0 即有问题
python tools/count_checks.py    # 文档说的项数 == 实际跑出的项数，不一致拒绝打包
```

**注意**：仓库副本（`skill/learn-system/`）和已安装副本（`~/.workbuddy/skills/learn-system/`）是两个独立目录。
只改仓库不部署 = 跑的还是旧版本。`build.py` 会自动部署，审计 U 段会拦下不一致。
